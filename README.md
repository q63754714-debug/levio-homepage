# LEVIO 르비오 — 반응형 메인 페이지

코덱스가 작업 중인 홈페이지와 **별개로 신규 제작**한 반응형 메인입니다.
의존성 없는 순수 HTML / CSS / JS 이므로 `index.html` 을 브라우저로 열면 바로 확인됩니다.

```
levio-responsive-home/
├─ index.html
├─ assets/
│  ├─ css/style.css
│  ├─ js/main.js
│  └─ img/            ← 실사 이미지 넣을 자리 (현재 비어 있음)
└─ README.md
```

## 2. 패키지 렌더링 (`.pkg`) — **중요**

대표 이미지 생성용 크레딧이 없어, **실제 패키지 조형을 CSS로 재현**해 넣었습니다.

재현한 요소:
- 솔리드 컬러 박스 + 상단 크림색 반원 탭
- 세로 타원 디보싱 + 타원 위의 작은 도트
- `LEVIO · 르비오` → 영문 제품명(900) → 국문명 → 스펙 순서의 라벨 타이포
- 앰버 글라스 보틀 + 블랙 리브드 캡 + 동일 컬러 라벨

제품별 컬러는 실제 패키지에서 추출했습니다.

| 클래스 | 제품 | HEX |
|---|---|---|
| `.pkg--bio` | BIO 10B | `#6e7355` |
| `.pkg--collagen` | COLLAGEN GLOW | `#b0212c` |
| `.pkg--move` | MOVE 1200 | `#2c3a54` |
| `.pkg--active` | ACTIVE B8 | `#c8974b` |
| `.pkg--night` | NIGHT 02 | `#574860` |
| `.pkg--mag` | MAG 350 | `#e9e2d4` (도트 `#24407a`) |

### 실사 사진으로 교체하는 법
`.pkg` 블록 전체를 `<img>` 하나로 바꾸면 됩니다. 나머지 스타일은 그대로 동작합니다.

```html
<!-- 교체 전 -->
<span class="prod__thumb">
  <span class="pkg pkg--bio">…</span>
</span>

<!-- 교체 후 -->
<span class="prod__thumb">
  <img src="assets/img/bio-10b.jpg" alt="LEVIO BIO 10B 바이오 10B 제품 이미지">
</span>
```
`.prod__thumb` 은 `aspect-ratio:1/1`, `.deal__thumb` 은 `4/3` 이므로 그 비율로 준비하면 잘립니다.
`.pkg` 크기는 컨테이너 쿼리(`cqw`)로 카드 폭에 자동 비례합니다.

## 4. 스크립트 (`main.js`)

의존성 없는 IIFE 10개 모듈: 레이어팝업 · 히어로슬라이더 · 태그필터 · 카운트다운 ·
리뷰캐러셀 · 드로어+아코디언 · 검색 · 언어드롭다운 · 헤더/탑버튼 · 스크롤리빌.

- `prefers-reduced-motion` 존중 (자동재생·애니메이션 정지)
- 백그라운드 탭에서는 슬라이더 정지
- 키보드 조작(←/→, Esc) 및 포커스 이동 처리

타임세일 마감일은 HTML 에서 지정합니다:
```html
<section class="timesale" data-deadline="2026-12-31T23:59:59+09:00">
```

## 6. ⚠️ 실제 데이터로 교체가 필요한 항목

아래는 **제가 임의로 채운 값**입니다. 실제 값으로 바꿔주세요.

- **가격 전체** — 6개 제품의 정가·할인가·할인율 모두 임의값
- **리뷰 수 / 별점 / 후기 본문 / 작성자** — 전부 예시
- **핫딜 문구** — "2개 구매 시", "정기구독 시" 등 조건 임의
- **회원 혜택** — 2,000P / 정기구독 25% / 적립률 등 임의
- **푸터 사업자 정보 전체** — 상호·대표·사업자번호·통신판매업신고·주소·계좌·CS 전화 모두 `000` 플레이스홀더
- **인스타그램 계정** — `@levio_official` 로 가정
- **브랜드 스트립 문구** — "12단계", "HACCP" 등 검증 필요

### 식품유형 표기 주의
COLLAGEN GLOW 패키지에는 **`일반식품` / 식품유형 `기타가공품`** 으로 명시돼 있어 그대로 반영했습니다.
나머지 5종의 식품유형(건강기능식품 여부)은 확인되지 않아 **표기하지 않았습니다.**
건강기능식품이 아닌 제품에 기능성 표현을 쓰면 표시광고법 위반 소지가 있으므로,
제품별 식품유형을 확인한 뒤 상세 문구를 확정해 주세요.

### 연락처
COLLAGEN GLOW 패키지의 소비자상담 번호는 개인 휴대폰 번호로 보여, 공개 페이지에
그대로 넣지 않고 플레이스홀더로 두었습니다. 게시할 번호를 지정해 주세요.
