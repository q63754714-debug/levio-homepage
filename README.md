> 뱃지 · 장바구니 카운트 · 버튼 호버처럼 **흰 글씨가 올라가는 곳은 `--c-accent-deep`** 을 쓰세요.

## 2. 섹션 구성

상품 그리드를 여러 번 반복하지 않고, 성격이 다른 섹션을 교차 배치했습니다.

1. **히어로** (3슬라이드) — 포장 라인 / NIGHT 02 제품컷 / 원료 계량 씬
2. 마퀴 티커
3. 브랜드 스트립 — 아이콘 + 숫자 카운트업
4. **The Lineup** — 6종 제품 그리드 (해시태그 필터) *유일한 상품 진열*
5. **Find my routine** — 고민 선택/입력 → 제품 추천
6. **Today’s Drop** — 에디토리얼 배너
7. **Process** — 원료·공정 4단계
8. About / Membership 분할
9. **Time sale** — 배경 사진 + 단일 대표 딜 + 카운트다운
10. Real Review 캐러셀
11. Instagram 그리드
12. 푸터

## 3. 모션 · 그래픽

- 히어로 켄번즈 줌, 스크롤 패럴랙스(배경·제품·장식)
- 패키지의 **타원 디보싱을 장식 모티프**로 차용 (부유 애니메이션)

- `prefers-reduced-motion` 존중 — 모든 모션 정지

## 6. ⚠️ 배포 시 주의

CSS/JS를 수정하면 **`index.html`의 `?v=` 값을 올려야** 합니다.
```html
<link rel="stylesheet" href="assets/css/style.css?v=6">
<script src="assets/js/main.js?v=6"></script>
```
GitHub Pages가 에셋을 캐시하기 때문에, 이 값을 안 올리면 기존 방문자에게 구버전이 적용됩니다.

### 식품유형 표기 주의
COLLAGEN GLOW 패키지에는 **`일반식품` / 식품유형 `기타가공품`** 으로 명시돼 있어 그대로 반영했습니다.
나머지 5종은 확인되지 않아 **표기하지 않았습니다.** 건강기능식품이 아닌 제품에 기능성 표현을 쓰면
표시광고법 위반 소지가 있으므로, 제품별 식품유형 확인 후 문구를 확정해 주세요.
