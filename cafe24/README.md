# 르비오 카페24 자사몰 — 진행 상황

카페24 쇼핑몰(`leviooffical.cafe24.com`)에 올린 디자인 두 종의 소스와 작업 기록입니다.

## 결과물

| 디자인 | 주소 | 소스 | 상태 |
|---|---|---|---|
| 메인 (대표 디자인) | https://leviooffical.cafe24.com/ | `cafe24/skin3-final.html` | 배포 완료 |
| LEVIO LAB | https://leviooffical.cafe24.com/skin-skin4/ | `cafe24/skin4-lab.html` | 배포 완료 (라인업 개편분 미반영) |

두 파일 모두 **CSS·JS가 전부 인라인된 단일 HTML**입니다. 카페24 스마트디자인 편집기의 `/index.html`에 통째로 넣는 방식이라 외부 스킨 파일 의존이 없습니다. `<!--@layout()-->` 지시자를 제거해 레이아웃 없이 단독 렌더링됩니다.

이미지는 카페24 CDN(`ecimg.cafe24img.com`)에, 폰트는 jsDelivr / Google Fonts에 있습니다.

## 1. 메인 디자인 (`skin3-final.html`)

기존 자사몰 구조가 "구매 상품 / 기준 / 성분표" 반복이라 피로하다는 피드백에서 출발해 재구성했습니다.

**구성** — 히어로 → 실시간 타임세일 밴드 → 증상 기반 제품 추천 → 원료·제조 스토리 → 표시 기준 도넛 → 제품 그리드 → 정기구독 계산기 → 포토리뷰 → 문의

**주요 기능**
- 타임세일 실시간 카운트다운 (상단 알림바 + 본문 밴드 동기화)
- 증상 다중 선택 → 제품 1종 + 조합 추천
- 퀵뷰 모달, 위시리스트, 최근 본 상품, 무료배송 게이지
- 정기구독 할인 계산기
- 포토리뷰 12건 + 라이트박스
- 캡슐에 내용물이 차오르는 문의 버튼, 카카오톡 문의 버튼
- 표시 기준 도넛 차트 (`@property`로 `conic-gradient` 애니메이션)

## 2. LEVIO LAB (`skin4-lab.html`)

juvelook.com 과 project-pef.com 의 연출을 참고해 만든 별도 디자인입니다.

**스택** — GSAP + ScrollTrigger + Lenis(스무스 스크롤)

**스크롤 연출**
- 히어로: 풀스크린 사진이 `clip-path`로 접혀 프레임이 되고, 배경이 다크→크림으로 전환 (project-pef 방식)
- 인트로: 섹션 핀 고정 `+220%`, 제품 컷이 아래에서 솟아 위로 통과 + 마우스 3D 틸트
- 기술: 섹션 핀 고정 `+150%`, 두 컷이 어긋나게 겹친 편집형 콜라주 + 아래에서 위로 닦이는 clip 리빌
- 라인업: 세로 스크롤이 그대로 **가로 레일 이동**으로 (화살표·도트 없음). 모바일은 스와이프
- 배경에 워드마크 6줄이 30~40초 주기로 세로 순환
- 그레인 오버레이, 커스텀 커서, 무한 마퀴, 스펙 카운터

**타이포**
- 한글 SUIT Variable / 라틴 Space Grotesk — 둘 다 각진 지오메트릭
- 한 줄 안에서 `200 ↔ 700` 굵기 대비
- `word-break:keep-all` + `text-wrap:balance`로 한글 문단 정렬

**색** — 제품 사진에서 직접 추출 (배경 크림 `#faf8f5`, 액센트 패키지 크림슨 `#a4232f`, 회색·그림자 전부 웜 계열)

## 남은 작업

### 실제 값으로 교체 필요
소스에 `⚠` 주석으로 표시해 두었습니다.

- **사업자 정보** — 상호·대표·사업자등록번호·통신판매업신고번호 (현재 `—`)
- **카카오톡 채널 URL** — 현재 빈 링크
- **MAG 350** — 제품명·성분·가격이 추정값
- 메인: 리뷰 12건 문구·작성자·날짜, 타임세일 종료 시각, 정기구독 할인율, 제조공정 4단계 설명
- LAB: 기능성 근거 8건 (고시형 원료 기준으로 임시 정리)

### 기능 한계
**장바구니·주문이 실제 결제로 이어지지 않습니다.** 쇼핑몰에 상품이 등록되어 있지 않아 카페24 장바구니로 넘겨도 담기지 않습니다. 상품 등록 후 각 제품에 `product_no`를 연결해야 합니다.

### 기타
- 디자인 목록에서 LAB의 이름이 「디자인 시안2」로 남아 있음 (카페24 관리자 입력창이 React 기반이라 자동 변경 불가, 수동 수정 필요)
- 링크 공유 시 상대방에게 빈 화면이 뜬다는 보고 — 익명 요청·모바일 UA 모두 정상 응답이라 원인 미확인. 접속 제한(IP) 설정 확인 필요
